## Fase A — PR-53b (336 templates short+long)

**Output**: `nest/src/database/migrations/1746000250000-M42bDiagnosticTemplatesShortLong.ts`.

1. Carregar via SQL os 168 templates existentes (M42, size=medium) agrupados por `(metric_id, severity, direction)`.
2. Para cada combinação, gerar **par short+long** preservando vocabulário do medium correspondente:
   - **short** ≤120 char, foco no fato observado, máx 1 placeholder.
   - **long** parágrafo ~300–500 char, pode usar todos os 5 placeholders permitidos.
   - Verbos da linha vermelha: só `observa-se | indica | apresenta | tende a apresentar`. Severity=strong nunca usa "severo" → "considerável".
   - Cada template precisa passar 4 gates do `TemplateRendererService`.
3. **Paralelização**: 3 subagentes Opus, um por grupo:
   - **A.1** symmetry+thirds+fifths (5+3+6=14 métricas × 3 sevs × 2 sizes = 84 templates)
   - **A.2** eyes+brows+nose+mouth (6+6+7+7=26 × 3 × 2 = 156)
   - **A.3** jaw+cheekbones+forehead+global (6+5+3+2=16 × 3 × 2 = 96)
4. Main agent agrega no array `SHORT_LONG_TEMPLATES`. INSERT idempotente com `ON CONFLICT (version, metric_id, severity, direction, size) DO NOTHING`. `placeholders_used` JSONB derivado por regex.
5. `npm run typeorm:run` + `npm run lint:templates` + `npm test` + `npx tsc --noEmit`.

**Critério de pronto A**: 336 novas linhas em `diagnostic_template`; lint exit 0; 201/201+ Vitest verdes; tsc clean.
